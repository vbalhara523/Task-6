# Data Science Capstone Project: Telco Customer Churn & Segmentation

## Objective
This is an integrative capstone project demonstrating a full data science pipeline using Python. It combines both **unsupervised learning** (K-Means clustering for customer segmentation) and **supervised learning** (Random Forest for churn prediction) on the public Telco Customer Churn dataset.

## Project Phases
1. **Data Acquisition & Cleaning**: Handled missing values in numeric columns and prepared the dataset.
2. **Unsupervised Modeling**: Applied K-Means to segment users based on tenure and monthly charges.
3. **Supervised Modeling**: Implemented a Random Forest Classifier to predict if a customer will churn.
4. **Evaluation**: Evaluated the classification model using Precision, Recall, F1-Score, and Confusion Matrix.

## Requirements
- Python 3.x
- pandas
- numpy
- matplotlib
- seaborn
- scikit-learn

## How to Run
Run the pipeline script via terminal:
`python capstone_pipeline.py`
